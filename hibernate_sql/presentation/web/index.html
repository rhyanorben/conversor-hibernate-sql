Hibernate → PostgreSQL

Cole a SQL e os logs de binding. Gere a query com os valores preenchidos para testar no PostgreSQL.

Como usar

Cole os logs ou arraste um arquivo .log ou .txt para este painel para converter automaticamente em SQL sem comando adicional.

Logs misturados são separados automaticamente quando a thread está identificada nos registros de SQL e binding. Os erros indicam a query, a linha e o parâmetro envolvidos, quando disponíveis.

Os logs são enviados ao servidor desta aplicação para conversão. Nenhuma query é executada pela aplicação. EXPLAIN ANALYZE executa a query quando você a roda no PostgreSQL.
